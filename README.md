### 🚀 Featured Projects

#### 🧠 [PaperMind — AI PDF Research Assistant](https://github.com/) · *Live Demo*
`Next.js` `React.js` `FastAPI` `Supabase (PostgreSQL + pgvector)` `Gemini API` `PyMuPDF`
- Production-ready **RAG platform** for semantic search and conversational querying across multiple PDFs with grounded, page-level citations.
- End-to-end pipeline: PyMuPDF parsing → sliding-window chunking → Gemini Embeddings → pgvector retrieval.
- Cut backend memory usage by **85%+** via the serverless Gemini Embedding API, enabling deployment on Render's free tier.

#### 🏥 [QMedix — Smart Hospital Queue & Appointment System](https://github.com/) · *Live Demo*
`Node.js` `Express.js` `Supabase (PostgreSQL + Realtime)` `React.js` `Jest` `Supertest`
- Full-stack hospital queue & appointment system with **role-based access control** for patients, doctors, staff, and admins.
- OOP-based `queueEngine` built on **Supabase Realtime** (no raw WebSockets) delivering sub-100ms client-side queue updates.
- Database-view–backed schema for fast pre-aggregated rendering; **30+ Jest/Supertest API tests** wired into CI.

#### 💰 [PromptLedger — AI Tool Cost Audit & Optimization Platform](https://github.com/) · *Live Demo*
`Next.js` `TypeScript` `Tailwind CSS` `Supabase` `Upstash Redis` `GitHub Actions`
- Full-stack MVP auditing organizational AI tool spend and recommending cost-effective alternatives.
- Owned system design and business logic for cost comparison & recommendation generation.
- Automated pricing refresh workflows via **GitHub Actions**; rate-limited with **Upstash Redis** for load resilience.
